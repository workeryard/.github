# Contributing

Issues and pull requests are welcome. A few things make them easier to take:

- **Show how you checked.** A change in behaviour comes with what it was
  checked against — a test, a server, a measurement — and the result before
  and after.
- **Run the checks.** Each repository's readme says how; usually
  `make check`.
- **Keep it small.** One change per pull request, with tests. A new
  dependency needs a reason, and a measurement of what it adds to a
  Worker's bundle.
- **Write it in English** — code, comments and commits alike. A commit says
  in its subject what it does, imperatively, and in its body why.

If a change is large, open an issue first, so its shape can be agreed before
the work is done.
